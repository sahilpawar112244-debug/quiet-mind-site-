About the upload tool

THE QUIET MIND is run by one independent creator. To publish videos, the creator uses a private command-line tool that uploads finished videos to the channel through the YouTube Data API v3.

  • What it does: uploads the channel's own videos and Shorts, with their title, description, tags, thumbnail and English captions, and checks that each upload finished processing.
  • Who uses it: only the channel owner. It is not offered to the public, has no other users, and signs in only with the channel owner's own Google account.
  • Which channel: only THE QUIET MIND (channel ID UCqY5ysTJuTZITzH_DJ6wLfw).
  • AI disclosure: the videos use an AI-generated voiceover, and every upload is marked as altered or synthetic content so YouTube shows its label to viewers.

The tool uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service.

Privacy policy

Last updated: 16 October 2026

This policy explains what the upload tool does with data. In short: it works only with the channel owner's own account, keeps very little, and shares nothing.

What data the tool accesses. Using YouTube API Services, the tool accesses only:

  • the channel owner's own channel name and channel ID, to confirm it is signed in to the right channel;
  • the upload status, privacy setting and duration of videos it has just uploaded to that channel.

It does not access, collect or process data about any other YouTube user, viewer or channel.

What data is stored. The tool keeps a private log of the channel's own uploads: video ID, title and upload date. No other YouTube data is stored. The log is kept for the life of the channel.

Sign-in and security. The tool signs in with Google OAuth. The resulting access credentials are stored privately, readable only by the channel owner, and are never placed in code, logs or shared files.

Sharing. No data is sold, shared with or shown to anyone else. The tool has no advertising, analytics or tracking.

Cookies. This page and the tool set no cookies.

Google's privacy policy. Because the tool uses YouTube API Services, Google's handling of data is covered by the Google Privacy Policy.

Revoking access. Access granted to the tool can be removed at any time from the Google account's security settings: myaccount.google.com/permissions. When access is removed, the stored credentials stop working.

Deleting data. To ask about or delete the upload log, use the contact address below. A reply will be sent within 30 days.

Changes. If this policy changes, the date at the top of this section will be updated.
